# Galyarder Labs

**Research · Systems · Software · Real Work**

Galyarder Labs is a small research studio. We build software that turns what
someone means into work that actually gets done.

## What we work on

The studio works on one problem: what happens between someone saying what they
want and the work actually getting done. We research it, build the software that
carries it, and test it against real work.

## Niyatna

That work became **Niyatna**, which takes a plain description of a company and
turns it into agents that can handle the daily tasks.
